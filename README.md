# لعبة المافيا 🌙 — React Native (Expo)

لعبة المافيا للجلسات العائلية على **جوال واحد** (نظام «مرّر الجوال»). شخص واحد يمسك الجوال كـ«محاوِر» والتطبيق يدير توزيع الأدوار سرّاً، ويقود مراحل الليل والنهار، ويحسب الفائز تلقائياً.

## التشغيل

```bash
npm install
npx expo start
```

ثم افتح التطبيق بإحدى الطرق:
- **جوالك:** نزّل تطبيق **Expo Go** وامسح رمز QR الظاهر في الطرفية.
- **محاكي iOS:** اضغط `i` (يتطلب Xcode).
- **محاكي Android:** اضغط `a` (يتطلب Android Studio).

## سير اللعب داخل التطبيق
1. **إعداد:** اختر عدد اللاعبين وأسماءهم، وفعّل الأدوار (اقتراح تلقائي جاهز).
2. **توزيع:** مرّر الجوال لكل لاعب ليرى دوره سرّاً (المافيا يرون شركاءهم).
3. **الليل:** التطبيق يقودك خطوة بخطوة (مافيا → طبيب → محقق → قنّاص).
4. **النهار:** يُعلن القتلى، نقاش، ثم تصويت بالأغلبية لإعدام مشتبه.
5. تتكرر الجولات حتى يفوز فريق — ويُكشف كل الأدوار.

## الأدوار المدعومة
مافيا · الأب الروحي · الطبيب · المحقق · القنّاص · المهرّج · مدني.

## بنية الكود
```
App.js                  آلة الحالة والتنقل بين الشاشات
src/game/engine.js      منطق اللعبة (توزيع، حلّ الليل، الفوز)
src/data/roles.js       تعريف الأدوار
src/data/distribution.js التوزيع المقترح حسب العدد
src/screens/            الشاشات (Home, Rules, Setup, Deal, Night, Day, GameOver)
src/components/         مكوّنات مشتركة (Button, Screen, PlayerChip)
src/theme.js            الألوان والمسافات
```
